☕️ Java 100 Fundamentals Challenge
A collection of 100 Java programming challenges and solutions designed to practice and strengthen fundamental Java programming concepts.
The project is organized into 10 topic-based packages, with 10 programming problems in each package. Every problem includes its corresponding Java source code solution.
The goal of this repository is to build a strong foundation in Java through practical problem-solving, from basic syntax and variables to arrays, loops, methods, error handling, and dialog boxes.
